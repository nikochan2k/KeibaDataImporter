はじめに
【ご挨拶】
日頃より「競馬道OnLine」サービスをご愛顧いただき、有り難うございます。
競馬道OnLineは、1997年10月にサービスを開始致しまして、大変多くのユーザーの
皆様をはじめ、ソフト制作者の方々にご支持いただき、お蔭様で順調に伸び続けて
おります。その間、非常に多くのご意見を賜り、今日まで皆様方の意見に添うよう
検討を重ねて参りました。競馬道OnLineは、皆様のご意見を重視して、豊富で正確
なデータ提供を追求し続けます。今後とも引き続き競馬道OnLineを宜しく御願い申
し上げます。
