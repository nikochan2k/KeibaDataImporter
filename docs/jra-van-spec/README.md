# JRA-VAN データ仕様書 (第3次 JRA-VAN データ Ver 3.1.1, 2002-06-07)

`Jvds3.1.1.xls` の各シートを、読みやすいように CSV (UTF-8) にしたもの。取り込み処理は [../jra-van.md](../jra-van.md) を参照。

| シート | ファイル |
|---|---|
| a データフォーマット | `spec/a-data-format.csv` |
| b コード表 | `spec/b-code-table.csv` |
| c 特記事項 | `spec/c-notes.csv` |
| d データ種別 | `spec/d-data-types.csv` |
| e 登録ファイル名 | `spec/e-file-names.csv` |

(f 登録単位、g データ料金 は取り込みに関係ないので変換していない)

## 読み方

- 項目表の「位置」は **1 始まり**。取り込み処理のアドレス(0 始まり)にするには 1 を引く。
- 繰り返しの項目の中の項目の位置は、繰り返しの 1 件目の先頭を 1 とした相対位置 `(  1)`。
- レコードの最後は CR LF (レコード区切)。レコード長は「レコード区切の位置 + 1」で、d シートのサイズと一致する。
- 既定値 `0` は数値の項目の初期値、`sp` は空白。
