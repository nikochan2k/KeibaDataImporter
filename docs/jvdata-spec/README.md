## 読み方

### b-data-format.csv (レコードフォーマット)

レコード種別ごとに、見出しの行(`２．レース詳細` の行。レコード長が入っている)と項目の行が続く。列は次のとおり。

| 列 | 内容 |
|---|---|
| B | 項番(繰り返しの中の項目は空) |
| C | 繰り返しの中の項目の記号(a, b, …) |
| D | キー(○はレコードのキー) |
| E | 項目名 |
| F | 位置(**1 始まり**)。繰り返しの中の項目は、繰り返しの 1 件目の先頭を 1 とした相対位置 `(  1)` |
| G | 繰返し回数 |
| H | バイト数(1 件分) |
| I | 合計バイト数(繰り返し全体) |
| J | 初期値(`0` は全部 `0`、`sp` は全部半角空白、`Ｓ` は全角空白) |
| K | 説明 |
| L〜 | データ区分ごとの設定の有無(○設定する、-初期値、△設定することも、しないこともある) |

- 取り込み処理のアドレス(0 始まり)にするには、位置から 1 を引く。繰り返しの 2 件目以降は、`バイト数 × 件数` を足す。
- レコードの最後は `レコード区切`(CR LF)。レコード長は「レコード区切の位置 + 1」で、見出しの行のレコード長と一致する。
- レコードの先頭は、レコード種別 ID(2 バイト、`RA` など)、データ区分(1 バイト)、データ作成年月日(8 バイト)。キーの「年月日場回日R」(開催年 4、開催月日 4、競馬場コード 2、開催回 2、開催日目 2、レース番号 2)は 12 バイト目(位置 12)から。
- 文字は Shift JIS。全角は 2 バイト、半角(英数・半角カナ)は 1 バイト。
- **JRA-VAN Data Lab. で提供するレコードの収録順序には仕様がない**。レース詳細より先に馬毎レース情報や払戻が来てもよいようにしておくこと。

### d-code-table.csv (コード表)

`2001.競馬場コード` のように、コード表の見出しの行があり、続く行の C 列がコード、D 列がコードの内容。

### 第3次 JRA-VAN データ(3.1.1)からの主な違い

- ファイルではなく、レコード種別 ID ごとのレコード(`RA` レース詳細、`SE` 馬毎レース情報、`HR` 払戻、`O1`〜`O6` オッズ、`UM` 競走馬、`KS` 騎手、`CH` 調教師 など)。馬番 19〜28 の分割はなく、1 レコードに全馬が入る(馬毎レース情報は 1 頭 1 レコード)。
- 賞金の単位は百円(3.1.1 は千円)。払戻金は円。
- 3 連単のオッズ・払戻・票数がある。オッズは組番を持っていて、無投票・発売前取消などの組も並ぶ。
- コード表で増えたもの: グレード `L`(リステッド)、トラック `25`〜`28`(ダート内回り・外回り、サンド)、競走記号 `N04` など、馬記号 `40` `41`、東西所属 `4`(外国招待)、騎手見習 `4` `9`、競走条件 `005` `010` `016`(1〜3 勝クラス)。
